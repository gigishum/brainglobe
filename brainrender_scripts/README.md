* Copy and paste these scripts directly into the napari console and run them
* Make sure you change the file path for detected cells to the actual .npy file from brainmapper
* Change the brain region/gene name as you wish, most likely it's the Allen nomenclature
* You can find more examples on these scripts in [brainrender's github](https://github.com/brainglobe/brainrender/tree/main/examples)
